# Airport Taxi - Ride Offers Platform

Platform for connecting airport travelers with taxi suppliers for negotiated ride offers. Built for the Intern Hackathon (Problem 2).

## Features
- **Traveler Flow**: Enter flight & hotel, see suggested route price ranges, post ride requests with custom offer prices, and book or reject taxi offers.
- **Supplier Flow**: View eligible ride requests based on airport/operating area/hours, assign cars within the route price limits, and handle booking updates.
- **Rules Engine**: Validates passenger capacity, bag constraints, airport-city connectivity, pickup lead times, and car availability windows.
- **Booking & Changes**: Generates a 10-digit booking reference and handles flight/pickup change requests.

## Project Structure
- `problem-statement/`: Complete specification and requirements documents.
- `data/`: Hackathon input datasets (catalog, routes, suppliers, requests).
